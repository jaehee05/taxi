# 🚕 택시 미터기

친구를 태워줬을 때(혹은 그냥 기다려줬을 때) 밥값을 청구하기 위한 장난용 택시 미터기입니다.
서울 중형택시 요금 체계를 그대로 흉내 냅니다.

## 요금 계산

| 항목 | 기본값 |
|---|---|
| 기본요금 | 4,800원 (1.6km까지) |
| 거리요금 | 131m당 100원 |
| 시간요금 | 15.33km/h 미만 주행·정차 시 30초당 100원 |
| 심야할증 | 22~23시 20% · 23~02시 40% · 02~04시 20% |

- 기본거리(1.6km)를 다 쓰기 전까지는 미터가 올라가지 않습니다.
- 기본거리 소진 후에는 속도에 따라 **거리요금 또는 시간요금 중 하나만** 적립됩니다. 실제 택시 미터기와 같은 방식입니다.
- 최종 요금은 심야할증을 곱한 뒤 100원 단위로 반올림합니다.

요금표는 앱 안의 **설정**에서 전부 수정할 수 있습니다. 요금이 인상됐거나, 장난용으로 "1분에 1만원" 같은 걸 만들고 싶을 때 쓰세요.

## 기능

- GPS 기반 실시간 거리·속도 측정 (정확도 60m 초과 신호와 GPS 튐 현상은 걸러냄)
- 정차/저속 시 자동으로 시간요금 전환
- 운행 중 화면 꺼짐 방지 (Wake Lock)
- 하차 시 영수증 발행 → 공유하기로 카톡 전송
- 운행 기록 및 손님별 **누적 미수금** 집계
- 시뮬레이션 모드 — GPS 없이 가상 주행으로 데모 가능 (설정에서 켜기)

## 사용법

폰 브라우저로 배포된 주소를 열고, 손님 이름을 넣은 뒤 **운행 시작**을 누릅니다.
목적지에 도착하면 **운행 종료** → 영수증이 나옵니다.

> 위치 권한이 필요하므로 HTTPS 환경에서만 정상 동작합니다. 로컬에서 열면 `localhost`는 예외적으로 허용됩니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

Vercel 정적 호스팅. 빌드 과정 없이 파일 그대로 올라갑니다.

```bash
vercel --prod
```
