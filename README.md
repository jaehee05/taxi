# 🚕 택시 미터기

친구를 태워줬을 때(혹은 그냥 기다려줬을 때) 밥값을 청구하기 위한 장난용 택시 미터기입니다.
서울 중형택시 요금 체계를 그대로 흉내 냅니다.

## 요금 계산

설정에서 **성남·분당** 또는 **서울** 지역을 고르면 해당 요금표와 시 경계가 함께 적용됩니다. 기본값은 성남·분당입니다.

| 항목 | 성남 · 분당 (경기) | 서울 |
|---|---|---|
| 기본요금 | 4,800원 (2km까지) | 4,800원 (1.6km까지) |
| 거리요금 | 132m당 100원 | 131m당 100원 |
| 시간요금 | 31초당 100원 | 30초당 100원 |
| 심야할증 | 00~04시 20% | 22~23시 20% · 23~02시 40% · 02~04시 20% |
| 시계외 할증 | 시 경계 밖 구간 요금의 20% | 좌동 |

> 요금표는 제작 시점 기준으로 넣은 값입니다. 실제 미터기와 대조해서 다르면 설정에서 고쳐 쓰세요. 특히 경기도는 시군마다 심야할증 시간대가 다를 수 있습니다.

미터기는 거리와 시간을 **하나의 '효과거리'로 합쳐서** 계산합니다. 실제 택시 미터기와 같은 방식입니다.

- 기준속도 이상으로 달리면 실제 주행거리가 그대로 효과거리로 쌓입니다.
- 기준속도 미만(저속·정차)이면 흐른 시간이 거리로 환산돼 쌓입니다. 환산율은 `거리단위 ÷ 시간단위`이고, 그래서 기준속도도 이 둘에서 유도됩니다 — 서울은 `131m ÷ 30초 = 4.37m/s(15.72km/h)`, 경기는 `132m ÷ 31초 = 4.26m/s(15.33km/h)`.
- **기본거리도 정차 시간으로 깎입니다.** 화면의 `기본거리 1,600m 남음`이 멈춰 있어도 초당 4m씩 줄어드는 이유입니다. 완전히 정차만 해도 약 6분이면 기본요금 구간이 소진됩니다.
- 기본거리를 다 쓴 뒤부터 효과거리 `거리단위`마다 100원씩 오릅니다.
- 시계외 할증은 **시 경계 밖에서 쌓인 효과거리**에 해당하는 요금에만 붙습니다. 전체 요금에 붙는 게 아닙니다.
- 최종 요금은 `(미터요금 + 시계외 할증) × 심야할증`을 100원 단위로 반올림합니다. 두 할증은 중복 적용됩니다.

시계외는 실제 택시처럼 **시계외 버튼**을 눌러 켜고 끕니다. 설정에서 *시계외 자동 판정*을 켜면 GPS가 선택한 지역의 시 경계를 벗어날 때 알아서 켜집니다 — 성남·분당이면 강남·잠실·수지·광주로 나가는 순간 붙는 식입니다. 다만 경계 폴리곤이 근사치라 경계 부근에서 1~2km 오차가 있고, 버튼을 한 번 누르면 그 운행 동안은 자동 판정이 멈추고 수동이 우선합니다.

요금표는 앱 안의 **설정**에서 전부 수정할 수 있습니다. 요금이 인상됐거나, 장난용으로 "1분에 1만원" 같은 걸 만들고 싶을 때 쓰세요.

## 기능

- GPS 기반 실시간 거리·속도 측정 (정확도 60m 초과 신호와 GPS 튐 현상은 걸러냄)
- 정차/저속 시 자동으로 시간요금 전환
- 시계외 할증 토글 (지역 시 경계 기반 자동 판정 옵션)
- 성남·분당 / 서울 지역 요금표 프리셋
- 운행 중 화면 꺼짐 방지 (Wake Lock)
- 하차 시 감열지 모양 영수증 발행 — 톱니 절취선, 상품명/단가수량/금액 3단, 바코드
- 요금을 기본요금·주행요금·할증으로 항목화. 100원 단위 반올림분은 단수조정 항목으로 드러내
  항목의 합이 언제나 합계와 맞는다
- **PNG 이미지로 생성**해 카톡 등으로 바로 전송 (링크·텍스트 공유도 가능)
- 운행 기록과 **누적 미수금** 집계, 기록은 건별로 삭제 가능
- 시뮬레이션 모드 — GPS 없이 가상 주행으로 데모 가능 (설정에서 켜기)

## 사용법

폰 브라우저로 배포된 주소를 열고 **운행 시작**을 누릅니다.
목적지에 도착하면 **운행 종료** → 영수증이 나옵니다.

> 위치 권한이 필요하므로 HTTPS 환경에서만 정상 동작합니다. 로컬에서 열면 `localhost`는 예외적으로 허용됩니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Firebase / Firestore

운행 기록을 클라우드에 저장하고, 영수증을 링크로 공유하고, 손님별 미수금 장부를 씁니다.
Firebase 연결에 실패하면 앱은 자동으로 localStorage 모드로 떨어져 그대로 동작합니다.

### 콘솔에서 켜야 하는 것

1. **Authentication → Sign-in method → 익명** 사용 설정
   켜지 않으면 `auth/configuration-not-found` 로 클라우드가 비활성화됩니다.
2. **Authentication → Sign-in method → Google** 사용 설정
   설정 화면의 *구글 계정 연결* 로 기기 간 동기화를 하려면 필요합니다.
3. **Authentication → Settings → 승인된 도메인** 에 Vercel 배포 도메인 추가
4. **Firestore → 규칙** 에 `firestore.rules` 배포

```bash
npx firebase-tools deploy --only firestore:rules --project taxi-6c0c5
```

### 데이터 구조

| 경로 | 용도 | 접근 |
|---|---|---|
| `users/{uid}/trips/{id}` | 운행 기록 | 본인만 읽기·쓰기 |
| `receipts/{id}` | 공유 영수증 | 링크를 아는 사람은 읽기, 목록 조회 불가, 발행자만 삭제 |

익명 로그인으로 시작하므로 로그인 화면이 없습니다. 다만 익명 계정은 기기마다 다르므로,
폰과 PC에서 같은 기록을 보려면 설정에서 **구글 계정 연결**을 한 번 해야 합니다.
익명 계정에 구글 계정을 얹는 방식이라 그때까지 쌓인 기록은 그대로 보존됩니다.

규칙은 필드 화이트리스트와 숫자 상한을 걸어 두었습니다. 로그인만 하면 문서를 쓸 수 있는
구조라, 저장소로 악용되지 않도록 막아 둔 것입니다.
